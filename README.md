# 🥐 Bun in the Oven - Study Tracker

A cozy, Ghibli-inspired study timer that bakes a virtual bun while you focus. 

## Features
- **Focus Timer:** A Pomodoro-style timer with a bun that bakes when you focus and burns if you leave the tab.
- **AI Study Buddy:** Powered by Ollama (Gemma 2) and Groq, the app generates study summaries and quizzes when your session ends.
- **Dynamic Dashboard:** Tracks your study hours with a color-coded, stacked bar chart and subject breakdown.

## Tech Stack
- HTML / CSS / Vanilla JavaScript (Frontend)
- Python (Backend Server)
- Ollama (Gemma 2) / Groq API (AI)

## How to Run Locally
1. Install [Ollama](https://ollama.com) and run `ollama run gemma2:2b`.
2. Run the python server: `python server.py`.
3. Open `index.html` in your browser.
